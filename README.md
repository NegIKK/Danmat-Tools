# Danmat Tools

**[Download from Gumroad]()** | **[Report Bug]()**

Утилитный аддон для 3D-художников, который помогает管理工作 с булевыми операциями, Geometry Nodes и подготовкой объектов к bake. Если вы много работаете с high-low poly и используете булевые или геометри — этот аддон сэкономит вам массу времени.

![Main Panel](images/main-panel.png)

---

## Что оно делает?

Представьте: у вас есть модель с 5-10 булевыми вырезами, зеркалами и геометрическими нодами. Обычно вам нужно:

- Следить какие объекты являются утилитами (какой булеан за что отвечает?)
- По очереди их скрывать/показывать призаolit
- Переименовывать объекты в _low/_high для bake

**Danmat Tools** автоматизирует всё это. Один клик — и группа переименована. Прокрутка колесом — и вы быстро переключаетесь между утилитами с визуальным подтверждением.

---

## Установка

1. Скачайте архив аддона
2. Blender → Edit → Preferences → Add-ons
3. Нажмите **Install** и выберите архив
4. Включите аддон чекбоксом
5. Панель появится в N-panel → вкладка **Tool** (или ваша кастомная категория)

---

## Основные функции

### 🔤 Быстрое переименование (_low / _high)

Выделите все объекты bake-группы, выберите **Rename** — и аддон автоматически расставит суффиксы: активный объект станет `_low`, остальные получат `_high`.

![Rename GIF](images/rename-demo.gif)

- **Alt + клик** — переименовать и сразу перейти в local view
- После переименования можно автоматически:
  - Поставить lowpoly в wireframe
  - Скрыть всю группу

> **Настройка**: `Digits Separator` — какой разделитель использовать для цифр (по умолчанию точка). Например: `Cube.001_low` или `Cube_001_low`.

---

### 🎯 Выделение bake-группы

Нажмите **Select Bake Group** — и аддон найдёт все объекты с таким же базовым именем и выделит их. Не нужно вручную искать и выделять `Cube_high`, `Cube_high.001`, `Cube_low` — всё произойдёт автоматически.

![Select Group GIF](images/select-group.gif)

- **Alt + клик** — выделить группу и перейти в local view

> Как это работает: аддон вычисляет "базовое имя" — отрезает цифры дубликатов и суффиксы _low/_high, затем ищет все объекты с таким же корнем.

---

### 👁 Скрытие/показ утилит

Кнопка **Toggle Utils** скрывает или показывает все объекты, которые используются в модификаторах активного объекта (Boolean, Mirror, Geometry Nodes).

![Toggle Utils GIF](images/toggle-utils.gif)

> Утилиты — это те объекты, на которые ссылаются модификаторы. Например, если у вас есть Boolean → Difference с объектом `Cutter_01`, то `Cutter_01` — утилита.

---

### 🔄 Модальная навигация по утилитам (фишка аддона)

Самая мощная функция. Запускаете **Manage Utils** → и видите оверлей со списком всех утилит активного объекта:

![Overlay GIF](images/overlay-demo.gif)

| Ввод | Действие |
|------|----------|
| `Wheel ↑` / `Wheel ↓` | Переключение по списку |
| `ЛКМ` | Подтвердить и закрыть |
| `Esc` / `ПКМ` | Отмена (вернуть как было) |

Пока вы крутите колесо — аддон:
1. Скрывает предыдущую утилиту
2. Показывает текущую
3. Делает её активной (опционально)
4. Подсвечивает в оверлее

> **Настройка "Exclude Mirror"** — не показывать зеркальные объекты (они обычно не нужны в списке)
> **Настройка "Set Active"** — делать выбранную утилиту активным объектом (нужно для редактирования)

## Настройки аддона

Blender → Edit → Preferences → Add-ons → Danmat Tools

| Параметр | Описание |
|----------|----------|
| **N-Panel Category** | Название вкладки в N-panel (по умолчанию "Tool") |

Настройки внутри панели (Scene Properties):

| Параметр | Описание |
|----------|----------|
| **Digits Separator** | Разделитель для цифр `.` или `_` |
| **Set LP to Wire** | После rename поставить lowpoly в wire |
| **Hide After Rename** | После rename скрыть всю группу |
| **Exclude Mirror Objects** | Не показывать mirror-объекты в списке |
| **Set Utility Active** | Делать утилиту активной при навигации |

## Как это работает (технически)

**Поиск утилит**: Аддон ищет объекты в модификаторах:
- Standard modifiers (Boolean, Array, etc.) — через POINTER properties
- Geometry Nodes — через `mod.keys()` и `mod.items()`

**Поиск группы**: `get_base_name()` убирает:
1. Цифры в конце (Blender дубликаты)
2. Суффиксы _low / _high
3. Разделители `. _ -, ; : /`

Затем ищет все объекты начинающиеся с этого корня.
